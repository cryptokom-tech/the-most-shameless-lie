Entry for [The Most Shameless Lie](https://make.fun/c/u-danu-the-most-shameless-lie-fbb85bc6) bounty on [make.fun](https://make.fun).

`main.py` (Python 3, standard library only) writes one original lie — 5 words, 25 characters, a single line — to `/output/entry.txt`:

> I never sent that email.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
